# 自动结算检查与实现状态（2026-11-09）

本次将此前清单中的手动结算项接入新对局的自动规则流程。旧版辅助存档仍按原行为加载，避免凭空推断缺失的圆片、工人分配、港口和道路记录；新对局使用 `rulesVersion: 2`。

| 原缺口 | 新对局实现 |
|---|---|
| 过路费 | 选择合法路线后，自动按实际板块计算黑手／绿手费用、收款者、余额不足减免及免缴能力；莎拉从供应区代付 |
| 建造与替换 | 按建筑面、需求差和行动来源计算工匠及费用，限制合法空位、开拓者门槛、替换所有权；保留地图上的茂草与风险属性 |
| 雇工 | 按市场行及行动折扣／加价收款，限制工人列容量，排入对应即时奖励 |
| 奖励市场 | 禁止购买市场标记当前行，按价格表和行动加价付款，处理万能工人金块、永久能力、交换、移除卡牌和天灾等效果 |
| 地点资格和次数 | 中立建筑两面、私有建筑 a／b 面均有行动定义；各行动每次停留限一次，附属替代行动与地点行动互斥；当前行动结算完才能继续 |
| 开拓者与认证 | 经过金块格、移动上限奖励、11 格二选一、开拓者终点溢出钱币及认证经过金块格自动结算 |
| 采购 | 根据购买方案分配牧羊人，自动价格和紫羊交换奖励；补市场也消耗本次工人分配 |
| 剃毛 | 根据行动来源和剩余剃毛工限制数量，按不同品种计算收入，处理抽换及羊毛贸易站后续 |
| 运送和圆片 | 校验门槛、重复运送、圆片颜色与解锁费用；自动贸易站奖励；支持白边耗尽和中型港口回收例外 |
| 附属行动 | 按实际已移除圆片确定种类和次数，自动费用、抽换和后续移动 |
| 卡牌 | 牧羊犬、渡轮、翠鸟、五类功能奖励卡和普通／奖励目标即时效果接入；目标不补抽，功能卡在效果后补抽；特殊分支由玩家选择 |
| 目标与固定计分 | 按当前物件求最高合法目标分配，不重复使用同一物件，已打出的失败目标扣分；建筑、天灾、奖励、港口、仓库连线、港务长、手牌上限和工人格计分接入 |
| 陆路 | 以固定节点及有向道路计算可到达地点，空格不计步，抵达威灵顿停止；首次玩家出发可任选中立建筑 |
| 海路 | 以海路节点及双向连接计算步数；升级消耗一步并结束移动；校验港口、仓库、圆片、港务长及外贸解锁 |
| 莎拉地图 | 按到威灵顿最少步数、最低总费用、最低玩家收入筛选路线；筛选玩家前方合法建筑空位及最低分港口；并列选项仍由玩家决定 |
| 建筑设置 | 支持全部 a 面、全部 b 面和随机混合；全体玩家使用相同配置 |

## 数据修正

- 本地 1 号站是获得 2 元、终局得 1 分，不是负分；1 与 3 号站的连线为 −3 分。
- 外贸 13 号站印刷分数为 8；两个海外羊毛贸易站单独归类。
- 莎拉新对局开局奖励市场只放 1 片。
- 预测完成后把剩余板块移至右侧，新板块补左侧。
- 新建建筑的地图金块奖励按所选特殊建筑格处理；风险行动须停在自己的建筑并支付弃牌代价。
- 建筑 b 面独立记录需求、分数及手图示，不能沿用 a 面数值。

## 验证范围

`tests/new-zealand-automation.test.cjs` 检查费用和奖励事务、地点与次数限制、采购分配、卡牌效果、圆片回收、预测顺序、海路不穿越港口、目标物件不重复，以及三档难度沿真实路线走至自然终局。

浏览器检查覆盖新建对局、路线选择、行动与奖励、莎拉选择、建造费用、撤销、刷新存档、自动计分和手机布局。测试不是所有策略组合的穷举，也不能替代后续规则勘误；数据仍以用户提供的规则与贴图为来源。

## 地图操作与自动选择改进

- 建造先点选建筑卡，再在地图选择合法空位或替换目标；确认时展示工匠和费用。航海、港口升级及贸易站运送使用地图高亮目标，选择后仅显示相关圆片、仓库或派工字段。
- 莎拉在自动规则对局中，唯一移动路线、唯一建筑方案及唯一港口连续自动结算；真正并列时停止，保留玩家选择。自动步骤与触发操作属于同一撤销记录，保留回合结束的查看机会。
- 采购先点击绵羊，按数量、品种、剩余牧羊人和钱币匹配方案。只有一个方案时自动选中；工人与费用存在取舍时必须选择，不自动替玩家决定。
- `tests/new-zealand-interactions.test.cjs` 覆盖采购匹配、建造位置与费用、航海步数与升级、莎拉唯一选择与并列暂停。浏览器验证地图实际点击、取消与撤销、港口仓库、贸易站、采购两种匹配情况及手机布局。

## 独立绘制界面

- 浏览器加载规则清单后，将所有卡牌、板块正反面、地图与参考图替换为本项目代码生成的 SVG，不请求原版图片。莎拉行动卡由当前行动定义生成文字卡面。
- 路线图根据逻辑节点和连接绘制，陆路中点箭头指示前进方向，海路虚线表示双向连接。地图使用大字地点标记，卡牌详情显示完整行动与数值。
- 玩家板使用当前对局的能力、圆片、仓库与工人记录；游戏内规则入口采用文字说明，不再链接含原版美术的 PDF。
- 配件 ID、规则数据及保存结构保持不变，现有存档继续使用。原始资料仅保留在仓库中供规则核对，不作为界面素材加载。
- `tests/new-zealand-original-ui.test.cjs` 验证全部绘图入口、规则数据保留及新对局一致性；浏览器检查确认网络中没有 `/assets/` 图片请求，地图操作、采购、撤销及手机布局通过。

## 手机工作区与图标

- 手机使用独立的行动、地图、手牌、市场、牧场页面，固定底部导航；地图和手牌的当前确认操作固定在导航上方，无需滚过地图寻找按钮。
- 阶段变化时定位到相关页面：移动到地图、抽换弃牌和运羊到手牌，其余结算到行动页。建造、航海和运送选点自动进入地图并框定目标区域，切换页面保留选牌和地图位置。
- 手机卡牌为两列，地图可滚动和缩放，路线选择及详情使用底部弹层；横竖屏和桌面布局切换不重建对局。
- 原创线形图标覆盖工人、资源和导航：羊／锤子／帆船／剪刀标示四类工人，图标旁保留名称，工人卡面与地图板块使用相同图形。
- 浏览器实际点击验证底部确认、路线选择、建造与航海、运羊、弃牌、撤销、页面切换保留选牌及横竖屏布局。
